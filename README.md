# Tatame PWA

Aplicação para controle de praticantes, treinos e presenças de uma academia de Jiu-Jitsu.

## Tecnologias

- React e Vite
- Node.js e Express
- Sequelize
- PostgreSQL
- PWA

## Pastas

- `frontend`: aplicação React/PWA.
- `backend`: API Express e modelos Sequelize.

## Publicação

- Código: https://github.com/felipenwn/tatame-pwa
- Aplicação: https://tatame-pwa.vercel.app
- API: https://tatame-api-qc0d.onrender.com

## Execução local

Crie o banco `tatamepw` no PostgreSQL e copie `backend/.env.example` para `backend/.env`. Depois execute `npm install` e `npm start` dentro de `backend`. Em outro terminal, execute `npm install` e `npm run dev` dentro de `frontend`.
